# ⏱️ Stopwatch Application

A sleek and functional Stopwatch Application built using HTML, CSS, and JavaScript. This stopwatch provides essential features like start, stop, and reset, wrapped in an elegant user interface.

## 🚀 Features :-

Start Stopwatch :- Begin the timer with precision, counting seconds, minutes, and hours.

Pause Functionality :- Pause the stopwatch without losing the current time.

Reset Stopwatch :- Reset the timer to 00:00:00 with a single click.

Real-Time Display :- Updates every second with formatted time (hh:mm:ss).

Stylish UI :- Beautifully designed with a gradient background and smooth typography.

## 💡 How It Works :-

Start the Timer :- Click the start button to begin counting.

Pause the Timer :- Pause the stopwatch without resetting the time by clicking the stop button.

Reset the Timer :- Reset the time to 00:00:00 and stop the timer with the reset button.

## 🛠️ Technologies Used :-

HTML: Structure of the stopwatch and buttons.

CSS: Styling for the layout, gradient background, and button alignment.

JavaScript: Logic for timer control, time formatting, and DOM updates.
